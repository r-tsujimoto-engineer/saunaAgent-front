# saunaAgent-front

## テスター向け情報

### 必要条件
- LINEアプリ（最新バージョン）
- テスターとして登録されたLINEアカウント

### アクセス方法
1. LINE公式アカウントを友だち追加
2. メニューから「サウナエージェント」を選択

### テスト手順
1. アプリにアクセス
2. 各機能の動作確認
   - サウナ施設検索
   - お気に入り登録
   - 履歴確認
   など

### フィードバック方法
不具合や改善点を発見した場合：
1. スクリーンショットを撮影
2. 発生手順を記録
3. 担当者に報告

### 注意事項
- テスト用データは実際のものと異なる場合があります
- 開発中の機能のため動作が不安定な場合があります
